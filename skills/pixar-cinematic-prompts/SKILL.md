# Pixar Cinematic Prompts — Consistent Silent 3D Animation Workflow

Generate production-ready prompts for high-fidelity Pixar-style 3D animations (image-to-video preferred). Emphasize photo-fidelity character consistency, emotional clarity, non-distressing medical accuracy, authentic Uzbek representation, vertical 9:16, and silent visual storytelling.

## Core Workflow

1. **Clarify the scene**  
   Extract: subject(s), emotion/arc, setting (home, clinic, Tashkent street, etc.), duration feel (slow push-in, dolly), key action, any medical or educational point, text/overlay needs (prefer none or minimal, certain).

2. **Lock character consistency**  
   - Describe face once with high specificity (age, skin tone, hair/hijab details, eye shape, expression baseline).  
   - Add: "identical facial features and proportions across all frames/shots, same character, no drift".  
   - For multi-shot: reference previous description exactly or use "same mother as previous, same child".

3. **Apply cinematic rules**  
   - Format: vertical 9:16.  
   - Lighting: golden hour or soft warm indoor, gentle particles, cinematic depth of field.  
   - Camera: slow push-in, gentle dolly, subtle zoom; natural motion only.  
   - Style: ultra-realistic Pixar/Disney 3D, expressive but natural facial animation, soft skin shading, detailed fabric.  
   - Audio: silent / no talk / ambient only (or specific sound design note).  
   - Avoid: talking mouths, distorted hands, inconsistent faces, harsh lighting, distress beyond educational need.

4. **Medical / educational scenes**  
   - Accurate but gentle visuals (no graphic trauma).  
   - Clear visual metaphors (glowing flow, shield, split-screen comparison).  
   - Parent-child emotional support emphasized.

5. **Output structure**  
   Deliver:  
   - Main prompt (one dense paragraph or structured).  
   - Negative prompt (optional but recommended).  
   - Shot notes (camera, lighting, consistency locks).  
   - Optional: 3-shot hero product workflow if requested (reveal → detail → emotional close).

## Consistency Locks (always include when relevant)

- Character face: "exact same facial structure, eye distance, nose, jawline, skin texture, and hair/hijab as reference"  
- Clothing / props: specific colors and materials  
- Environment continuity  
- Lighting continuity across cuts

## Common Adjustments

| Request | Action |
|---------|--------|
| More Uzbek authentic | Adjust skin tone, clothing (hijab style, patterns), architecture, names, family dynamics |
| No talk / silent | Explicitly state "silent, no dialogue, mouths closed or natural non-speaking" |
| Character consistency fix | Strengthen face description + "identical across frames" |
| Medical accuracy | Soften, add educational clarity, keep emotional warmth |
| Vertical 9:16 | Always specify aspect ratio and framing |
