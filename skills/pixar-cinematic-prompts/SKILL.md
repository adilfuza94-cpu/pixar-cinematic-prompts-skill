# Pixar Cinematic Prompts — Consistent Silent 3D Animation Workflow

Generate production-ready prompts for high-fidelity Pixar-style 3D animations (image-to-video preferred). Emphasize photo-fidelity character consistency, emotional clarity, non-distressing medical accuracy, authentic Uzbek representation, vertical 9:16, advanced cinematic lighting, and silent visual storytelling.

## Core Workflow

1. **Clarify the scene**  
   Extract: subject(s), emotion/arc, setting (home, clinic, Tashkent street, etc.), duration feel (slow push-in, dolly), key action, any medical or educational point, text/overlay needs (prefer none or minimal, certain), lighting mood.

2. **Lock character consistency**  
   - Describe face once with high specificity (age, skin tone, hair/hijab details, eye shape, expression baseline).  
   - Add: "identical facial features and proportions across all frames/shots, same character, no drift".  
   - For multi-shot: reference previous description exactly or use "same mother as previous, same child".

3. **Apply cinematic rules**  
   - Format: vertical 9:16.  
   - Lighting: choose from advanced techniques below; always soft skin shading, gentle particles where appropriate, cinematic depth of field.  
   - Camera: slow push-in, gentle dolly, subtle zoom; natural motion only.  
   - Style: ultra-realistic Pixar/Disney 3D, expressive but natural facial animation, soft skin shading, detailed fabric.  
   - Audio: silent / no talk / ambient only (or specific sound design note).  
   - Avoid: talking mouths, distorted hands, inconsistent faces, harsh unmotivated lighting, distress beyond educational need.

4. **Medical / educational scenes**  
   - Accurate but gentle visuals (no graphic trauma).  
   - Clear visual metaphors (glowing flow, shield, split-screen comparison).  
   - Parent-child emotional support emphasized.

5. **Output structure**  
   Deliver:  
   - Main prompt (one dense paragraph or structured).  
   - Negative prompt (optional but recommended).  
   - Shot notes (camera, lighting, consistency locks).  
   - Optional: 3-shot hero product workflow if requested (reveal → detail → emotional close).

## Advanced Lighting Techniques

Use these in prompts for emotional depth, dimensionality, and cinematic quality. Always keep lighting continuous across shots and flattering for skin (subsurface scattering feel).

| Technique | Best for | Prompt keywords |
|-----------|----------|-----------------|
| Golden hour / magic hour | Warm emotional family moments, outdoor | soft golden sunlight from side/back, long warm shadows, gentle rim light, floating dust motes, warm color temperature |
| Blue hour / twilight | Quiet intimate or reflective scenes | cool blue ambient with warm practical accents, soft sky glow, subtle rim |
| Rim / backlight | Separation, halo effect on hair/hijab, ethereal | strong rim light from behind, edge lighting on hair and shoulders, subject slightly shadowed in front |
| Rembrandt | Classic portrait emotion, indoor | key light 45° creating triangle of light on cheek, soft fill, deep but not harsh shadows |
| Butterfly / paramount | Beauty, hero product close-ups | key light high and slightly in front, soft shadow under nose, flattering even skin |
| Split lighting | Dramatic tension or duality | light on one side of face, other side in soft shadow, high contrast but still soft edges |
| Volumetric / god rays | Magical, spiritual, outdoor morning | visible light beams through haze or window, soft particles catching light, atmospheric depth |
| Practical lights | Homey interior authenticity | warm lamp glow, window light as key, motivated sources only, soft bounce from walls |
| Color contrast (warm/cool) | Emotional emphasis | warm key on subject, cooler background or vice versa, controlled complementary tones |
| Softbox / large source | Gentle medical or tender moments | large soft key light, minimal hard shadows, even flattering illumination, gentle falloff |

**Continuity rule:** Specify light direction, color temperature, and quality (soft/hard) so it matches across cuts.

## Consistency Locks (always include when relevant)

- Character face: "exact same facial structure, eye distance, nose, jawline, skin texture, and hair/hijab as reference"  
- Clothing / props: specific colors and materials  
- Environment continuity  
- Lighting continuity across cuts (direction, quality, color)

## Common Adjustments

| Request | Action |
|---------|--------|
| More Uzbek authentic | Adjust skin tone, clothing (hijab style, patterns), architecture, names, family dynamics |
| No talk / silent | Explicitly state "silent, no dialogue, mouths closed or natural non-speaking" |
| Character consistency fix | Strengthen face description + "identical across frames" |
| Medical accuracy | Soften, add educational clarity, keep emotional warmth |
| Vertical 9:16 | Always specify aspect ratio and framing |
| Stronger lighting mood | Choose specific technique from table and expand keywords |
